# test# iDetector

Démo simple pour tester un système de détection de faux messages.

## Démarrage local
1. Installer Vercel CLI :
   npm install -g vercel

2. Démarrer :
   vercel dev

3. Ouvrir :
   http://localhost:3000/test.html

## Déployer sur Vercel
1. Pousser ce projet dans GitHub.
2. Importer dans Vercel.
3. Déployer.

## Remarques
- L’analyse est heuristique pour un prototype.
- En production, il faudra :
  - une vraie base de données
  - stockage de signalements
  - sécurité et consentement
  - modèle IA
